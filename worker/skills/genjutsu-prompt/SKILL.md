# Genjutsu prompt

Whenever the user asks for a Genjutsu prompt, always write it using the template below. Do not change the fixed wording; only fill in the bracketed parts.

## What to collect
- Video length in seconds ([X]).
- Every change (swap) the user wants: objects, people, background, environment.

If the length or the changes are missing, ask for them in one short question before writing the prompt.

## How to write the swaps
- Each swap gets its own item: what it replaces, what it becomes, and its key visual traits (color, material, size, lighting).
- If the background or environment changes, add that lighting and shadows on the person match the new environment naturally.
- Be visually specific.

## Template

This is a recreation of my own original ~[X]-second vertical iPhone UGC video. I own @video_1 and all rights to it.

@video_1 is the full reference for everything in the output — person, actions, shot structure, cut timing, camera angles, framing, and iPhone UGC realism. Keep everything in the foreground absolutely identical to @video_1.

The ONLY changes:
(1) [Describe every swap here — objects, people, background, environment. Be visually specific.]
(2) The output contains absolutely NO text, NO captions, NO subtitles, NO emoji, NO graphic overlays anywhere in the video — zero text of any kind at any moment.
(3) The output contains absolutely NO audio of any kind — no voiceover, no music, no ambient sound, no sound effects. The final video is completely silent.

[X] seconds total, vertical 9:16. Ultra-realistic iPhone UGC look throughout, completely silent output with zero text.

## Output
Give the finished prompt in a single code block so it is easy to copy. Write the prompt in English, even if the user writes in another language.
